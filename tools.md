# Toolbox

## Recon & DNS
- `whois`, `dig`, `host` — basics, preinstalled on Linux
- [subfinder](https://github.com/projectdiscovery/subfinder) — passive subdomain enum
- [amass](https://github.com/owasp-amass/amass) — deeper enumeration (own domains only)

## Web
- Google dorks — no install needed
- [Wayback Machine](https://web.archive.org)
- Wappalyzer — stack fingerprinting

## Metadata & Images
- [ExifTool](https://exiftool.org/) — read/strip metadata
- `foremost`, `binwalk` — file carving

## Usernames & People
- [sherlock](https://github.com/sherlock-project/sherlock) — username enumeration
- [WhatsMyName](https://whatsmyname.app)

## Infrastructure
- [Shodan](https://shodan.io), [Censys](https://search.censys.io)
- [crt.sh](https://crt.sh) — certificate transparency logs

## Note: install on Termux/Kali
Most of these install with `apt`, `pip`, or `go install`.
